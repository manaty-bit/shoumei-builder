# 証明ビルダー Ver.3 — 白紙から書けるようになる

中学2年生向けの「整数の性質の証明」学習アプリ。**選択肢で証明の型を学び、最後は異なる初見の類題を選択肢なしで証明**します。ブラウザで `index.html` を開けば動作します。

## 学習内容

- **証明をつくる**：各問題につき①4択で証明を完成 → ②重要な1行を自分で書く → ③文字の置き方・計算・結論の設計図 → ④異なる類題を白紙から証明
- **間違いを修復**：①誤りのある行を発見 → ②なぜ間違いか選ぶ → ③正しい1行を自分で書き直す
- **基礎**：証明8題、誤りの修復8題
- **発展**：証明13題、誤りの修復8題（図を用いる5題を追加）

## 図を使う題材

奇数を6列に並べた2×2、7列の自然数の2×2、カレンダーのL字型、階段状の長方形、偶数と奇数の和の表。

## 評価についての注意

自由記述を文字列一致で機械採点**しません**。入力後に模範証明と評価観点を表示し、本人が5観点で自己照合します。数学的に同値な別解を排除しないためですが、入力内容の正しさをシステムが保証するものではありません。授業での合格判定には、教師による答案確認を組み合わせてください。

- 選択問題の誤答とヒント利用を各記録に保存
- 白紙の初見類題は2日後にアプリ内で再挑戦可能（アプリを開いたときに利用できる方式）
- 全題終了で「学習達成記録」を印刷可能。合否の自動認定ではなく**学習履歴の証明**です
- データは端末内の `localStorage` に保存。ブラウザや端末を変えると共有されません
