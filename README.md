# 証明ビルダー Ver.5 / PROOF QUEST

中学1年生から使える「整数の性質の証明」学習アプリです。楽しさと数学的な正確さを両立させるため、**入力はなし・ボタン選択のみ**で、数を文字で表すこと、証明の流れ、誤った証明の修復に取り組みます。

## 画面・操作
- **PC優先の2カラム**：左にミッション（問題文・図）、右に4択と現在の証明
- **ページのスクロールを抑える設計**：1366×768、1280×720などではメイン画面を1画面内に表示（ブラウザの拡大率などで一部内部スクロールする場合があります）
- **スマホ**：画面幅に応じて縦1カラムへ自動切り替え。選択肢は大きめのボタン
- **数字キー1〜4**でも選択可能（誤り探しの行選択は1〜行数）
- 証明ノートは直前の1行を表示し、**「全体を見る」**でこれまでの証明を確認
- ナビキャラクター・進捗バー・ミッションクリア演出

## 2つの学習モード
1. **証明をつくる**：正しい文章を選択して、文字の置き方 → 式変形 → 整数である理由 → 結論と進む。任意の「ならべかえ」では順番も確認
2. **間違いを見抜く**：誤りの行 → 理由 → 修正案の順にボタンで選ぶ

- **基礎**：証明8題、誤り探し8題
- **発展**：証明13題、誤り探し8題。規則性の図も収録
- 学習記録は端末内の `localStorage` に保存（Ver.4のクリア状況も引き継ぎ）

## 目的
このアプリの目的は **証明の流れや文字の置き方を正しく理解すること** です。白紙から証明を書くことの判定や入力は行いません。必要に応じて授業・プリントで別に練習します。
