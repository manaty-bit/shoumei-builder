# 証明ビルダー — 整数の性質を証明しよう

中学校2年生向けの、選択式で学ぶ「整数の性質の証明」アプリです。インストール不要で、`index.html` をブラウザで開くだけで動きます。

## 学習モード

- **証明をつくる**：4択で正しい文章を順番に選び、証明を1行ずつ完成させる。
- **間違いを見抜く**：提示された証明を読み、誤りのある1行を選ぶ。正しい表現と解説を表示する。

各モードに **LEVEL 1 基礎（8問）**、**LEVEL 2 発展（8問）** を収録。合計32問です。

### 問題テーマ

奇数・偶数、倍数、連続する整数、余り、2～4けたの整数の各位の数字の入れ替え、各位の数字の和、カレンダーの十字形など。

## 使い方

GitHub Pages で公開する場合は、リポジトリの Settings → Pages → Deploy from a branch → main / (root) → Save を設定してください。

学習のクリア記録は同じブラウザ内に保存されます。問題・画面は今後更新予定です。
