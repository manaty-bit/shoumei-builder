# 証明ビルダー Ver.4 — ボタンで学ぶ整数の証明

中学2年生向けの「整数の性質の証明」学習アプリです。**入力不要。すべてボタン操作**で「文字の置き方」「式の変形」「証明の順序と理由」を学びます。

## 2つのモード

1. **証明をつくる**：4択から正しい文章を1行ずつ選んで、証明を完成させます。最初の行で文字の置き方と条件に注目し、計算・理由・結論へ進みます。
   - **順番チャレンジ（任意）**：証明の文章を正しい順序で選んで完成させる復習モードです。
2. **間違いを見抜く**：誤りがある行をタップ → 誤りの理由を4択で選ぶ → 正しい修正を4択で選びます。

## 難易度と問題数

- **LEVEL 1 基礎**：証明8題／間違いを見抜く8題
- **LEVEL 2 発展**：証明13題／間違いを見抜く8題
- 合計37題。証明21題は任意の順番チャレンジも用意しています。

図から考える題材には、6列の奇数表、7列の数表、カレンダーのL字型、階段状長方形、偶数と奇数の表などがあります。

## 学習のゴール

このアプリの目標は、**証明の流れと文字の置き方を正しく理解すること**です。白紙から証明を書く力の評価は、授業・紙の問題で別途行います。アプリのクリアは筆記試験の合格を意味しません。

## 動作と公開

- `index.html` をブラウザで開くだけで動作します。
- 回答にキーボード入力は必要ありません。
- 進捗は端末のブラウザ内（localStorage）に保存されます。Ver.3 の自己評価記録は引き継がず、Ver.4 の選択式記録として新規に保存します。
- GitHub Pages：Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
