# 証明ビルダー Ver.5 / PROOF QUEST

中学1年生から使える「整数の性質の証明」学習アプリです。楽しさと数学的な正確さを両立させるため、**入力はなし・ボタン選択のみ**で、数を文字で表すこと、証明の流れ、誤った証明の修復に取り組みます。

## 画面・操作
- **PC優先の2カラム**：左にミッション（問題文・図）、右に4択と現在の証明
- **ページのスクロールを抑える設計**：PCでは通常の回答画面を1画面に収め、問題一覧や補足を開いて内容が増えたときはページをスクロールできます
- **スマホ**：画面幅に応じて縦1カラムへ自動切り替え。選択肢は大きめのボタン
- **数字キー1〜4**でも選択可能（誤り探しの行選択は1〜行数）
- 証明ノートは直前の1行を表示し、**「全体を見る」**でこれまでの証明を確認
- ナビキャラクター・進捗バー・ミッションクリア演出。誤答時はその段階の着眼点を示し、クリア後は完成した証明や修復結果を振り返れます

## 2つの学習モード
1. **証明をつくる**：正しい文章を選択して、文字の置き方 → 式変形 → 整数である理由 → 結論と進む。任意の「ならべかえ」では、完成例の各段階に必要な役割を考える
2. **間違いを見抜く**：誤りの行 → 理由 → 修正案の順にボタンで選ぶ

- **基礎**：証明8題、誤り探し8題
- **発展**：証明13題、誤り探し8題。規則性の図も収録
- 学習記録は端末内の `localStorage` に保存（Ver.4のクリア状況も引き継ぎ）

## 目的
このアプリの目的は **証明の流れや文字の置き方を正しく理解すること** です。白紙から証明を書くことの判定や入力は行いません。必要に応じて授業・プリントで別に練習します。

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save で公開できます。

## 検証

- `node --test tests/content.test.cjs` で問題ID、選択肢、主な式変形と保存キーを確認できます。代入による検査は式変形の回帰確認に使い、文章による仮定・根拠・結論は教材レビューで確認します。
- Playwrightを利用できるPython環境で `python tests/browser_check.py` を実行すると、ローカルサーバーとヘッドレスChromeで3画面サイズの操作と学習記録を確認できます。`--screenshots DIRECTORY` で旧版との比較画像も保存します。
